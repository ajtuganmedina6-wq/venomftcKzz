# venomftcKzz
Біздің «VENOM» командасы 2022 жылы құрылды және сол уақыттан бері робототехника саласында белсенді дамып келеді. Біз халықаралық FIRST Tech Challenge және FIRST Global Challenge жарыстарына қатысып, көптеген беделді жүлделерге ие болдық. Командамыз тек робот жасаумен шектелмей, жас инженерлерді оқытуға, жаңа технологияларды
